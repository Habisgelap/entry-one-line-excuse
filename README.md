An entry for the [make.fun](https://make.fun) bounty
"The One-Line Excuse an Agent Gives Its Human".

`main.py` writes one line — the excuse an AI agent gives its human for
missing a deadline — to `/output/entry.txt`. The line is 160 characters
at most, as the gate requires.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
